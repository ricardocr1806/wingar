# Sistema Wingard

Sistema de gestão da Wingard dividido em três departamentos, um para cada etapa do atendimento:

1. **Comercial** – cadastro do cliente e do veículo, proposta de serviços, previsão financeira (entrada, parcelas, total) e painel de vendas.
2. **Operacional** – ordem de serviço, checklist de entrada e saída, gestão de pátio e impressão da OS e do Prisma.
3. **Financeiro** – conferência do que o Comercial combinou, confirmação dos recebimentos, liberação da entrega, contas a pagar/receber e DRE.

## Protótipo de interface

`prototipo/index.html` é um protótipo clicável (HTML + JS puro, sem instalação) com dados de exemplo, feito para validar telas e fluxo antes do desenvolvimento do sistema.
